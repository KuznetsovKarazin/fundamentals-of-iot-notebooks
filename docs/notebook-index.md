## How the files are organized

Each chapter has one main notebook under `notebooks/`. Filenames are stable and case-sensitive. Chapter 10 preserves the established repository filename `ch10-common-iot-sensors-practice.ipynb`; the chapter ZIP uses a different filename for the same notebook.

Open a notebook, read its setup cells, and run cells in order. The core exercises work without a physical board. Notebook models, simulated traces, and planning scores retain their stated assumptions and must not be described as collected hardware measurements.

Other teaching signals and inputs are generated or defined within their notebooks. Inspect data-status statements and random seeds before interpreting a result. Save exported files if you want to retain them after a Colab runtime ends.

## Link stability and reproducibility

GitHub is the versioned source for the companion package; the dated Drive ZIP provides a downloadable snapshot for teaching. Existing individual chapter Drive links are retained in the manuscript, but their synchronization is a separate publication task. When reporting a result, record the GitHub commit or release and the environment you actually used. A link to the moving `main` branch alone does not identify an immutable experiment.

If a GitHub-backed Colab link fails to load, download the notebook from GitHub or the checked Drive ZIP and upload a notebook to Colab. Refer to the [main README](../README.md) for local setup.
